Specifications (Buying your first PC)

Three tiers for After Effects. Each tier represents the minimum for that level of work.

After Effects prefers high clock speeds over extreme core counts. RAM matters more than type (DDR4 vs DDR5) on a limited budget.
Low-End
Basic editing and simple compositions.
RAM16 GB
SSD512 GB NVMe
CPUi5 12th / Ryzen 5 5600X
GPURTX 3050 / RX 6600
Tip: Better to spend extra on RAM than GPU.
Mid-Range
Intermediate comps with moderate effects.
RAM32 GB
SSD1 TB NVMe
CPUi7 13th / Ryzen 7 7700X
GPURTX 4060 / RX 6700 XT
Tip: Upgrade RAM before GPU.
High-End
Complex compositions, 4K footage.
RAM64–128 GB
SSD2 TB+ NVMe
CPUi9 14th / Ryzen 9 7950X
GPURTX 4080 / 4090
Tip: 128 GB only for complex 3D comps.

Which version of After Effects to install?

Install the latest version for bug fixes and recent features. If you have a low-end device, consider an older release.

What's new →  System requirements →

AE projects are not backwards compatible. To save in an older version: File › Save As › Save a Copy As (version).

What are plugins and which ones to install?

Plugins are non-native effects. Avoid collecting too many — they hurt storage and performance.

RSMB
Realistic motion blur on footage.
Magic Bullet Looks
Advanced color correction.
Twitch
Shake and jerky-style movements.
Twixtor
Smooth slow motion via frame-warping.
Universe
VHS look, glitch and many effects.
Sapphire
100+ effects: glow, glitch, warp.
BCC (Boris FX)
100+ unique effects and transitions.
Trapcode
Particles, swirl, burst.
Element 3D
3D text and models inside AE.
Saber
Outlines and lightsaber-style glow.
Deep Glow
Premium glow for text and PNG.
Optical Flares
Customizable flare transitions.

Composition Settings

1080p is more than enough for casual work. 4K requires powerful hardware and platforms compress it anyway.

30 FPSStandard — great for photos, animations, sports.
60 FPSIdeal for gaming edits and time interpolation.
23.976Cinema and AMV. Always match your source footage FPS.
15 FPS"Laggy" aesthetic. Use Posterize Time instead of comp settings.

How to save and import presets

Select what you want, then go to Animation › Save Animation Preset. Save to the correct path:

Windows
\Documents\Adobe\After Effects 2024\User Presets
Mac
~/Documents/Adobe/After Effects 2024/User Presets
Avoid Support Files\Presets — it's reserved for Adobe defaults.

MBLook + RGX Presets

Red Giant switched from .mblook to .rgx in version 14 of Magic Bullet Looks.

Version 13 and earlier — import .mblook:

Windows
C:\Program Files (x86)\LooksBuilder\Looks
Mac
/Library/Application Support/LooksBuilder/Looks/

Version 14+ — import .rgx:

Windows / Mac
Documents\Red Giant\Magic Bullet Looks\Presets
